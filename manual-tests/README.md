### Manual Testing File Information





##### File Structure \& Naming Conventions



|**Files** |**ID Format**|**Description**|
|-|-|-|
|**test-cases.xlsx**|TC-01, TC-02 ...|- Test cases are separated and uniquely identified by ID such as TC-01, TC-02...<br />- Each test case includes ID, Priority, Title, Test Type, Preconditions, Steps and Expected Result|
|**test\_cases\_Executions.xlsx**|TR-01, TR-02 ...|- Test Runs are separated and uniquely identified by ID such as TR-01, TR-02...<br />- Each Test Run includes ID, Priority, Title, Test Type, Preconditions, Pass/Fail Result, Steps, Expected Results and Actual Results|
|**bug-reports.md**|SD-01, SD-02 ...|- This file documented all defects identified during the test execution. Each issue is uniquely identified by ID like SD-01, SD-02, and SD-03. <br />- Each report includes the Bug ID, Title, Description, Steps to Reproduce, Expected Results, Actual Results, Severity, Priority and Evidence.|
|**Test\_Case\_Execution\_Evidence\_Files.zip**|TR-01.pdf, TR-02.pdf... |PDF (screenshots and execution logs) mapped 1 to 1 against each Test Run ID.|
|**Test Summary Report.md**|N/A|A general Overview report showing total test cases executed, pass/fail metrics, bug counts, and final quality verdict.|
